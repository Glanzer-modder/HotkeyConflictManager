# Hotkey Conflict Manager

View all your assigned keys for all mods and game actions in one place. Dynamic warnings are displayed when a key gets assigned more than once. Debug mode scans hotkey registrations and un-registrations in real time--even from scripts running in the background. MCM settings for complete control over mod functions. Compatible with everything.

For full documentation, see the Nexus location here: https://www.nexusmods.com/skyrimspecialedition/mods/180713
